# SCM Lab
Laboratório de Gerência de Configuração de Software.
Este repositório será utilizado para praticar conceitos de controle de versão, branches, issues, commits, pull requests, reviews, merge e tags.

## Objetivo
Praticar o uso do GitHub e os principais conceitos de Gerência de Configuração de Software.

## Sobre o projeto
O projeto tem como objetivo praticar conceitos de desenvolvimento de software e gerenciamento de configuração utilizando o GitHub.
